EmuFlix
EmuFlix is a C++20 desktop application that acts as a Netflix-style frontend for emulators. Built with Qt 6 and SQLite, it allows users to scan ROM folders, manage emulator settings, browse games in a modern shelf-based interface, and launch titles from multiple systems in one place. The application supports metadata tracking, favourites, recently played games, controller-first navigation, and persistent settings. Its purpose is to simplify emulator use by hiding technical setup behind a clean, unified, and user-friendly interface.

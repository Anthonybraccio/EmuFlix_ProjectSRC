EmuFlix Session 6 Test ROM Layout

Add the root folder in EmuFlix Settings:
    <unzipped location>/EmuFlixTestROMs

Supported extensions included:
    .nes .gb .gbc .sfc .smc .gba .n64 .z64

Unsupported files are included too, so you can verify they are ignored.
Subfolders are included, so you can verify scanning and duplicate handling
.
